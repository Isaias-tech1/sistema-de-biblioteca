# sistema-de-biblioteca
  Focamos em deixar o sistema bem intuitivo e facil de iniciar o cadastro e o login,
e a facilidade de aprender a mecher na interface do programa.

  Esse foi o meu projeto e de um colega meu aqui no senac de São Mateus, resolvemos 
fazer de uma biblioteca porque sentiamos falta na hora quando iamos pegar um livro 
para estudar.

  Esse progama ajuda bastante no controle dos livros que são liberados para o emprestimo,
ele tambem conta com uma area para adicionar livros e remover os livros que tem na 
biblioteca ate então.
